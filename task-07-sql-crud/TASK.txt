==============================================================================
TASK 07 - CRUD STATEMENTS (INSERT, UPDATE, DELETE)
==============================================================================

OBJECTIVE
------------------------------------------------------------------------------
Modify data safely in the Pizza Flight database using INSERT, UPDATE, and
DELETE.

IMPORTANT TIP:
Because these statements modify your local pizza_flight.mv.db file, you can
reset the database back to its original state at any time by running
database/schema_and_seed.sql in DBeaver (Alt+X).
Remember: do NOT commit changes to database/pizza_flight.mv.db!


EXERCISES
------------------------------------------------------------------------------
Write the SQL statement(s) for each of the following 8 tasks in solutions.sql.
Execute them in order on a fresh copy of the database to verify everything
works cleanly!

1. Add a new pizza (INSERT):
   Insert a new pizza into "pizzas":
     - name          : 'Hawaii'
     - category      : 'Special'
     - base_price    : 8.80
     - bake_time_sec : 185
     - is_vegetarian : FALSE
     - calories      : 840

2. Register a new customer (INSERT):
   Insert a new customer into "customers":
     - first_name      : 'Clara'
     - last_name       : 'Neumann'
     - email           : 'clara.neumann@example.com'
     - city            : 'Berlin'
     - loyalty_points  : 20
     - registered_date : DATE '2026-03-15'

3. Place a new order (INSERT into two tables):
   Record a new order for 'clara.neumann@example.com' (customer_id = 9 on a
   fresh DB) at machine 1 (PF-BER-01):
     - In "orders":
       machine_id = 1, customer_id = 9,
       order_timestamp = TIMESTAMP '2026-03-15 18:00:00',
       payment_method = 'APP', total_price = 13.00,
       order_status = 'COMPLETED'
     - In "order_items":
       order_id = 16 (on a fresh DB), pizza_id = 1 (Margherita),
       quantity = 2, unit_price = 6.50

4. Price increase (UPDATE with WHERE):
   Increase the base_price of all pizzas in the 'Meat' category by 0.50
   (base_price = base_price + 0.50).

5. Restock out-of-stock pizzas (UPDATE):
   In "machine_inventory", set quantity = 10 and
   last_restocked = DATE '2026-03-15' for all rows where quantity = 0.

6. Bring a machine back online (UPDATE):
   Update the machine with code = 'PF-MUC-01' so its status becomes 'ACTIVE'.

7. Delete an unused topping (DELETE):
   Delete the topping 'Garlic Sauce' from the "toppings" table.
   (Think: why does deleting 'Garlic Sauce' succeed, while deleting
   'Mozzarella' would fail with a foreign key error?)

8. Delete a cancelled order safely (DELETE with FK order):
   Delete order_id = 9 (which was CANCELLED).
   (Hint: because order_items references orders, you must delete the matching
   row(s) in order_items FIRST, and then delete the row in orders!)

------------------------------------------------------------------------------
1. Reset your database with database/schema_and_seed.sql, then run your entire

2. End every SQL statement with a semicolon (;).
3. Commit and push ONLY solutions.sql (not pizza_flight.mv.db) to YOUR OWN
