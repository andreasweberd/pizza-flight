==============================================================================
PIZZA FLIGHT - SAMPLE H2 DATABASE GUIDE
==============================================================================

This folder contains the ready-to-use H2 database for Tasks 4-8:

  - pizza_flight.mv.db   Pre-populated H2 (2.x) embedded database file.
  - schema_and_seed.sql  Full SQL script to recreate or reset the database.

WHY H2?
H2 2.x runs in standard ANSI/ISO SQL mode by default and needs no server
installation - just one local file in DBeaver. All SQL you write in this
project (GENERATED BY DEFAULT AS IDENTITY, FETCH FIRST ... ROWS ONLY,
standard JOINs, GROUP BY, CHECK constraints, DATE '...' / TIMESTAMP '...'
literals) is portable standard SQL.


CONNECTING WITH DBEAVER
------------------------------------------------------------------------------
1. Open DBeaver.
2. Click "Database -> New Database Connection" (or the "+" plug icon).
3. Search for "H2 Embedded" (make sure it says Embedded, NOT Server) and
   click "Next".
4. In the "Path" field, select the file "pizza_flight.mv.db" inside this
   database/ folder - AND REMOVE the ".mv.db" extension from the path!
     - Windows example:     C:\Users\yourname\pizza-flight\database\pizza_flight
     - Linux/macOS example: /home/yourname/pizza-flight/database/pizza_flight
   (If you leave ".mv.db" at the end, H2 creates a brand-new empty file
   called "pizza_flight.mv.db.mv.db" instead of opening the existing DB!)
5. Authentication:
     - Username: sa
     - Password: (leave empty)
6. Click "Test Connection...".
   - If DBeaver asks to download the H2 driver, click "Download".
   - You should see "Connected".
7. Click "Finish".
8. Expand "pizza_flight -> Schemas -> PUBLIC -> Tables" in the Database
   Navigator. You should see 8 tables:
     CUSTOMERS, MACHINE_INVENTORY, MACHINES, ORDER_ITEMS, ORDERS,
     PIZZA_TOPPINGS, PIZZAS, TOPPINGS.

TIP: Right-click the "pizza_flight" connection and choose
"SQL Editor -> New SQL Script" to run queries (Ctrl+Enter / Cmd+Enter).


RESETTING THE DATABASE
------------------------------------------------------------------------------
After running INSERT, UPDATE, DELETE, or CREATE/ALTER TABLE statements in
Tasks 7 and 8, you can reset the database back to its original state at any
time using EITHER method:

1. In DBeaver: Open "database/schema_and_seed.sql" and execute the entire
   script (Alt+X / Execute SQL Script).
2. With Git: Close your connection in DBeaver first, then run:
       git checkout -- database/pizza_flight.mv.db

NOTE: Do NOT commit changes to "database/pizza_flight.mv.db" in your branch.
Only commit your solutions.sql files (and your photos for Tasks 1-3).


DATABASE SCHEMA REFERENCE (FOR TASKS 4-8)
------------------------------------------------------------------------------
machines
  machine_id (PK), code (UNIQUE), city, location_name, status, installed_date
  * status: 'ACTIVE', 'MAINTENANCE', 'OFFLINE'

pizzas
  pizza_id (PK), name (UNIQUE), category, base_price, bake_time_sec,
  is_vegetarian, calories
  * category: 'Classic', 'Meat', 'Vegetarian', 'Special'

toppings
  topping_id (PK), name (UNIQUE), extra_price, is_vegan

pizza_toppings
  pizza_id (PK, FK -> pizzas), topping_id (PK, FK -> toppings)

machine_inventory
  machine_id (PK, FK -> machines), pizza_id (PK, FK -> pizzas),
  quantity, last_restocked

customers
  customer_id (PK), first_name, last_name, email (UNIQUE), city,
  loyalty_points, registered_date

orders
  order_id (PK), machine_id (FK -> machines),
  customer_id (FK -> customers, nullable), order_timestamp,
  payment_method, total_price, order_status
  * customer_id is NULL for walk-up guest orders
  * payment_method: 'CARD', 'APP', 'CASH'
  * order_status: 'COMPLETED', 'CANCELLED'

order_items
  order_item_id (PK), order_id (FK -> orders), pizza_id (FK -> pizzas),
  quantity, unit_price
